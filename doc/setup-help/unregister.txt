Unregister this package with the compiler.

Usage: cabal unregister [FLAGS]

Flags for unregister:
 -h, --help                   # Show this help text
 -v[n], --verbose[=n]         # Control verbosity (n is 0--3, default
                                verbosity level is 1)
 --builddir=DIR               # The directory where Cabal puts generated build
                                files (default dist)
 --cabal-file=PATH            # use this Cabal file
 --keep-temp-files            # Keep temporary files.
 --user                       # unregister this package in the user's local
                                package database
 --global                     # (default) unregister this package in the
                                system-wide package database
 --gen-script                 # Instead of performing the unregister command,
                                generate a script to unregister later
