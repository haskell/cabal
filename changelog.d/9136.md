---
synopsis: Regenerate the cache of a `file+noindex` repository when the repository changes
packages: [cabal-install]
issues: 9136
prs: 0000
---

`cabal-install` used to keep using the cache of a local `file+noindex` repository
after packages were added to or removed from it, which led to confusing solver
errors until the cache was deleted by hand. It now notices when the repository
has packages the cache doesn't know about (or the other way round), or when a
tarball, `.cabal` file or `preferred-versions` file is newer than the cache, and
regenerates the cache in that case. Builds also notice packages being added to or
removed from such a repository.
