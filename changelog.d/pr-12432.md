packages: [cabal-install]

---

The v2 commands used to ignore these options:

- `--user` and `--global`
- `--enable-deterministic` and `--disable-deterministic`
- `--ipid`, `--cid` and `--instantiate-with`
- `--disable-response-files`
- `--allow-depending-on-private-libs`
- `--coverage-for`
- `--ignore-build-tools`
- `--reinstall`, `--avoid-reinstalls` and `--upgrade-dependencies`
- `--shadow-installed-packages`
- `--root-cmd`
- `--only`, which was accepted but never shown

The v2 commands no longer accept and will error if given any of them.
