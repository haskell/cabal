- Moves the short `-g` option from `--ghc` to `--enable-debug-info`. A command
  line that used `-g` to select GHC is still accepted, but `-g` now emits
  debug info instead.
```diff
  $ cabal build --help
...
- -g, --ghc                    # Compile with GHC
+ --ghc                        # Compile with GHC
...
- --enable-debug-info[=n]      # Emit debug info (n is 0--3, default is 0)
+ -g[n], --enable-debug-info[=n]
+                              # Emit debug info (n is 0--3, default is 2)
```
