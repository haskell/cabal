PR 11252 "comment parser" lays the foundation for Cabal Exactprint to consume
user comments.

This PR is orthogonal to the final exactprint implementation and to the algebra
we chose to modify existing fields and/or generate new fields. It focuses on
making user comments available to any consumer.

The envelope format "field" format is notably used by the project files
(`*.project`) and package descriptions (`*.cabal`).
Its parser now annotates each of the parsed sections, fields and fieldlines with
their prior and following comments. Comments are annotated with the existing
annotation data type 'Position'.

`readFields*` family of functions now have their counterparts that parses with
comments, named `readFieldsConcrete*`.
