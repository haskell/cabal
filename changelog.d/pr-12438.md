synopsis: Parse the v2 command lines with optparse-applicative
packages: [cabal-install]
significance: significant
prs: 12438
issues: 5607
---

The project commands (the v2- ones and their bare defaults) now parse their
options and targets with `optparse-applicative`.

The only visible difference is in error messages for a mistyped option, which
now come from `optparse-applicative` and include a lengthy usage line listing
all possible options.

The parsing behaviour goes beyond `optparse-applicative` default behaviour:

- abbreviation of a long option is accepted,
- an exact name takes precedence over a longer option it is a prefix of,
- optional-argument options such as `-j` and `--allow-newer` work as before.
