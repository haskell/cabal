---
synopsis: Remove support for building with UHC
packages: [Cabal, cabal-install]
prs: 12623
issues: [10262]
significance: significant
---

Cabal no longer knows how to configure, build, install or register packages
with the Utrecht Haskell Compiler (UHC). UHC is no longer developed and
nothing tested its Cabal backend.

- The `Distribution.Simple.UHC` module is gone.
- `uhcProgram` is no longer exported by `Distribution.Simple.Program` and is no
  longer one of the `builtinPrograms`, so `--with-uhc`, `--uhc-options` and the
  `uhc-location` and `uhc-options` configuration fields are no longer
  recognised.
- The `--uhc` flag of `Setup configure` is gone.

The `UHC` compiler flavour stays in `Cabal-syntax`, so `.cabal` files that
mention `impl(uhc)` or `tested-with: UHC` still parse as before.
