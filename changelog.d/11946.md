---
synopsis: "Build with semaphore-compat 2.0, and use -jsem only with a GHC that speaks the same version of the protocol"
packages: [cabal-install]
prs: 12607
issues: [11946]
---

cabal-install can be built with semaphore-compat 2.0, which GHC 9.12.5 and
9.14.2 ship. `--semaphore` passes `-jsem` to GHC only when GHC and the
semaphore-compat that cabal-install is built with speak the same version of
the semaphore protocol; otherwise it falls back to `-j` with a warning.
