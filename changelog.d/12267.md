---
synopsis: Omit system library directories from pkg-config linker options
packages: [Cabal]
prs: 12267
issues: 11860
---

Cabal configures `pkg-config` with `PKG_CONFIG_ALLOW_SYSTEM_LIBS` set, which
causes it to emit `-L` options for directories that the linker already searches
by default (for example `-L/usr/lib`).  These options are redundant and, when
they end up ordered before a more specific `-L` option, they can cause the
wrong version of a library to be linked.

Cabal now queries `pkg-config` for its system library directories and omits
them from the `-L` options it records, so that the linker uses its default
search path (which is searched after any explicit `-L` options) for those
directories instead.
