---
synopsis: Include all libraries in the `--haddock-for-hackage` docs tarball
packages: [cabal-install]
prs: 12366
issues: 12364
---

Fix a bug where `cabal haddock --haddock-for-hackage` created a
`<pkgid>-docs.tar.gz` containing the haddocks of only one library of the
package (e.g. only an internal library, or only the main library).

The haddocks of a package can be spread over several build units: the main
library and its internal libraries are built as separate units, each writing
its haddocks into its own build directory. Every unit created the tarball
from its own haddocks alone, writing to the same tarball path, so the tarball
left behind only contained the docs of whichever unit happened to finish
last.

Now the haddocks of all the units of the package are merged into a single
directory (in the layout that Hackage expects: the main library's docs at
the root, and each internal library's docs in a `<sublib>/` subdirectory)
before the tarball is created.
