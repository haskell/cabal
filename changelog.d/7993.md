---
synopsis: Explain solver failures caused by packages that come with the compiler
packages: [cabal-install-solver]
issues: 7993
prs: 0000
---

When the solver can't find a plan because a package that comes with the
compiler and can't be reinstalled (such as `base` or `template-haskell`) is in
the conflict, the error now ends with a note saying so, naming the compiler,
and suggesting either a different compiler or relaxing the version bounds on
that package. Previously the only hint was "constraint from non-reinstallable
package requires installed instance", which didn't make the connection to the
compiler version.
