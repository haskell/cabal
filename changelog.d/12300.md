`cabal test` used to abort with a successful exit status when one of the requested targets did not contain any test suites, silently skipping the tests of the other targets. Such targets are now skipped with a notice ("No tests to run for ...") and the tests of the remaining targets run.

```pre
$ cabal test pkg-with-tests pkg-without-tests
No tests to run for the package pkg-without-tests-0.1.0.0
Running 1 test suites...
Test suite pkg-with-tests-test: PASS
1 of 1 test suites (1 of 1 test cases) passed.
```
