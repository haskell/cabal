---


`cabal-install` used to invoke external `Setup` executables in the package
directory, while also passing them the package directory with `--working-dir`.
Now:

  - Packages with `build-type: Custom` or `Make` are invoked in the package
    directory, and are no longer passed `--working-dir`.
  - Other packages are invoked in the current directory (usually the project
    directory), and are passed a `--working-dir`. This is consistent with the
    in-library method.

The user guide has been updated to properly explain this.
