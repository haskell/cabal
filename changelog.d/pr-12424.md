---
synopsis: Keep line breaks and indent list items in command help text
packages: [Cabal, cabal-install]
prs: 12424
issues: 12422
---

`Distribution.GetOpt.usageInfo` used to re-flow an option's description as a
single run of words, so a description written with explicit line breaks lost
them. It now wraps each line on its own, and a line that starts with a `- `
list marker gets a hanging indent, so its continuation lines align with the
text after the marker.

The descriptions of `--show-details`, `--remote-build-reporting`,
`--prefer-version`, `--index-state`, `--profiling-detail`,
`--library-profiling-detail` and `--http-transport` now list their allowed
values one per line, and the placeholders of `--show-details`,
`--remote-build-reporting` and `--http-transport` name those values.
