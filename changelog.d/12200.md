---
synopsis: Change the default debug-info level from NormalDebugInfo to NoDebugInfo
packages: [Cabal, cabal-install]
prs: 12200
---

Change the default debug-info level from NormalDebugInfo (2) to NoDebugInfo
(0). The bare `-g` / `--enable-debug-info` form (any request that does not
specify a level) no longer enables debug info; explicit levels
(`-g1`, `-g2`, `-g3`, `--enable-debug-info=n`) are unchanged.

Explicit levels are also preserved for `build-type: Custom` and `Hooks`
packages: their setup scripts re-parse serialised configure arguments, so
`NormalDebugInfo` is now serialised explicitly (`--enable-debug-info=2`)
instead of as the bare form.

The `debug-info` entry is now omitted from the package hash inputs for
`NoDebugInfo` builds (previously it was omitted for `NormalDebugInfo`
builds), so the hash inputs no longer display a `debug-info` setting for
default builds. Note that this changes the computed package hashes of
packages built with the `debug-info` levels 0 and 2, which causes a
one-time rebuild of such packages after upgrading.
