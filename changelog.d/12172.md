---
synopsis: Allow commas inside braces in project package globs
packages: [cabal-install]
prs: 12172
issues: 12171
---

With `--project-file-parser=parsec`, the default parser, the `packages` and
`optional-packages` fields rejected a comma inside braces, so a glob such as
`../{foo,bar}/` failed to parse with "unexpected ','". These fields now accept
commas inside balanced braces, as `--project-file-parser=legacy` does.
