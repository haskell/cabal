synopsis: Create API for cabal-install
packages: [cabal-install, cabal-install-internal]
prs: 12359
---

The engine and the CLI layer of every command move to the new internal package `cabal-install-internal` (PVP-precise versioning, `cabal-install X.Y.Z.W` maps to `cabal-install-internal X.(Y*100+Z).W`). Tools that need more than the public tier can depend on `cabal-install-internal` with exact bounds.
