The `directory` and `clock` boot libraries shipped with GHC 9.12's JavaScript
backend reference RTS primitives (`h$fchmodat`, `h$CLOCK_*`,
`h$getNumberOfProcessors`) and `cryptohash-sha256` uses C FFI routines whose
`h$`-prefixed stubs the JavaScript runtime does not define. Calls into these
failed at runtime with `ReferenceError: ... is not defined`.

The `Cabal` library now ships these primitives as JavaScript `js-sources`
under `arch(javascript)` (`jsbits/js-backend-polyfills.js`), implementing
them on top of the primitives the runtime does provide. This can be removed
once the GHC JavaScript runtime in use implements the missing primitives
natively.
