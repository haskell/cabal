---
synopsis: Make package checks fast for packages with many conditionals
packages: [Cabal, cabal-install]
prs: 0000
issues: [11563]
---

Before checking each branch of a conditional (`if`/`else`) in a component,
Cabal adds to it what the other branches contribute. It used to take those
contributions from branches that already contained the whole enclosing component,
so a copy of the component was added for every branch. The time taken by
`checkPackage`, which runs during `configure` and `cabal check`, was therefore
quadratic in the number of conditionals, and proportional to the size of the
component. A package with 20,000 modules and 94 `if`/`else` blocks spent tens of
seconds in it; it now takes under a second.
