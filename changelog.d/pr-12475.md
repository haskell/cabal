---
synopsis: cabal-install supports SetupHooks.lhs (literate Haskell)
packages: [cabal-install]
prs: 12475
issues: 12473
---

`cabal build`:

* no longer reports an error if using `build-type: Hooks` and there is a
  `SetupHooks.lhs` file but no `SetupHooks.hs` file;

* warns that it is ignoring the literate Haskell file if both `SetupHooks.hs`
  and `SetupHooks.lhs` are present; and

* now also warns that it is ignoring the literate Haskell file (being the
  existing behaviour) if both `Setup.hs` and `Setup.lhs` (`build-type: Custom`)
  are present.
