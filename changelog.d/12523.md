---
synopsis: Fetch only the pinned commit of a git source-repository-package
packages: [cabal-install]
prs: 12531
issues: 12523
---

A `source-repository-package` from git is cloned with `--depth=1`, but the
commit that its `tag` or `branch` names was then fetched with all of its
history. Now only that commit is fetched, unless the checkout is already
complete (git clones a local path completely). A package that needs the
history can fetch it with `post-checkout-command: git fetch --depth=2147483647 --tags`.
