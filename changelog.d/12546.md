---
synopsis: Faster per-component configuring with many installed packages
packages: [Cabal]
prs: 12641
issues: [12546]
---

When configuring a component, Cabal built a graph of every installed package to
find the ones the component depends on. It now looks up only those, with the
new `Distribution.Simple.PackageIndex.dependencyClosureAndMissing`, which
`dependencyClosure` is now defined with.
