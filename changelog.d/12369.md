---
synopsis: The Show instance of Compiler renders valid Haskell source code
packages: [Cabal]
prs: 12369
---

The `Show` instance of `Distribution.Simple.Compiler.Compiler` now
renders `compilerWiredInUnitIds` with the exported smart constructors
`mkPackageName` and `mkUnitId`. The output of `show` can now be
embedded into generated Haskell modules, such as the environment module
generated by `cabal-testsuite`'s custom `Setup.hs`.
