---
synopsis: Fewer file system lookups when preprocessing modules
packages: [Cabal]
prs: 12606
issues: [10489]
---

When preprocessing a component, Cabal looked for a file with every known
preprocessor suffix in every source directory for every module, calling
`doesFileExist` each time. It now lists each source directory once, and uses the
listing to rule out files that do not exist. This speeds up the "Preprocessing"
step for packages with many modules, especially on Windows.
