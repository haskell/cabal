---
synopsis: Use Text instead of String in class FieldGrammar
packages: [Cabal-syntax]
prs: 12350
---

Moving towards using sensible string types in Cabal, we change members
of `class FieldGrammar` to return `Text` instead of `String`. Namely,
`freeTextField` and `freeTextFieldDef` now take a lens from `s` to `Text`
and a wrapper over `Text`. Further, `freeTextFieldDefST` is now no different
from `freeTextFieldDef` (because `type ShortText = Text`) and now is removed
together with its default implementation `defaultFreeTextFieldDefST`.
