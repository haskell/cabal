synopsis: Remove GHCJS
packages: [Cabal, cabal-install]
prs: 12396
issues: 11609
significance: significant
---

Removes GHCJS, the standalone compiler that predates the JavaScript backend of
GHC. The `Distribution.Simple.GHCJS` module, the `ghcjs` and `ghcjs-pkg`
programs, the `--ghcjs` flag and the GHCJS-only code paths are gone. Selecting
`compiler: ghcjs` now fails with an error that points at the JavaScript backend
of GHC. The `ghcjs-options` family of fields in a package description still
parse but have no effect. In a project file or the user config,
`ghcjs-options`, `ghcjs-location`, `ghcjs-pkg-options` and
`ghcjs-pkg-location` are now unrecognised fields and warn like any other.
