---
synopsis: Warn quoted component names
packages: [cabal-syntax]
issues: 12207
prs: 12223
---

In the library, executable or test section it is possible to assign a name within quotes.
A quoted name can contain spaces.
When a name contains spaces, it is impossible to refer to it in a build-depends fields because quotes are not allowed.
It is also impossible to refer to it in the CLI.
Quoting the name doesn't offer any benefit in the functionality of cabal-syntax.

Cabal will now issue a warning for quoted component names.
