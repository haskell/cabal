This command copies source tarballs of a project's dependencies, as selected by
the solver, into a directory laid out as a `file+noindex` package repository, so
that the project can be built without network access. It prints the `repository`
stanza to add to the project file.

`cabal build --offline` used to refuse any package that comes from a package
repository, including a `file+noindex` repository. Such a repository is a
directory on disk. Accessing its packages doesn't download anything, so
`--offline` works with them.

```console
$ cabal vendor
Vendored 12 packages into vendor

To build using the vendored packages, add the following to the project file
(the 'url' line must stay indented under 'repository'):

repository vendored
  url: file+noindex:vendor

active-repositories: vendored
```
