---
synopsis: Push Text.unpack to the fringes of the code base
packages: [Cabal-syntax, Cabal, cabal-install]
significance: significant
prs: 12599
---

What's `Text.pack`ed should not be `Text.unpack`ed gratuitously. We push unpacking `Text`
to the fringes of the code base (error messages, pretty printing, process invocations)
and strive to eliminate instances of it otherwise. This entails several changes, most notably:

* `unModuleName`, `unAbiHash`, `unComponentId`, `unFlagName`, `unPkgconfigName`, `unUnitId` now return `Text` not `String`,
* `customFieldsPD` field of `data PackageDescription` and corresponding lens now contain `[(Text, Text)]` not `[(String, String)]`,
* `argComponentName`, `argTitle` and `argPrologue` fields of `data HaddockArgs` now contain `Flag Text` not `Flag String`,
* `data LegacyExeDependency`, `data LegacyProjectConfig` now contain `Text` instead of `String`.
