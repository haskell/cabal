Fix a cabal-install 3.18 regression in which per-package `PROG-location=...`
fields in `cabal.project` files were ignored, e.g.

```
package p
  hsc2hs-location: /path/to/hsc2hs
```

Changes to the Cabal library:

  - `userSpecifyPath` now discards the previous configuration of a program
    when a different location for that program is specified.
  - `restoreProgramDb` no longer replaces already-known `Program`s.
