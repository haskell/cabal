---
synopsis: Resolve relative `file+noindex:` repository paths against the project root
packages: [cabal-install]
significance: significant
prs: 12522
issues: 10934
---

Like a relative path in `packages:`, a relative path in the `file+noindex:` URL
of a `repository` stanza in `cabal.project` now resolves against the project
root, whichever project file or import it is in. This lets a local repository be
committed together with the project. Such a path was accepted before but
resolved against the current working directory. Paths in the global
`~/.config/cabal/config` are unchanged.

For example, with this stanza in `cabal.project`:

```
repository my-local-repository
  url: file+noindex:repo
```

Running from a subdirectory of the project used to warn and then look for
`repo` under the subdirectory:

```diff
  $ cabal build all --dry-run
- Warning: file+noindex my-local-repository repository path is not absolute;
- this is fragile, and not recommended
- Warning: Error during construction of file+noindex my-local-repository
- repository index: repo: getDirectoryContents:openDirStream: does not exist (No
- such file or directory)
  Resolving dependencies...
```
