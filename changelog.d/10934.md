---
synopsis: Resolve relative `file+noindex:` repository paths against the project root
packages: [cabal-install]
prs: 0000
issues: 10934
---

A `repository` stanza in `cabal.project` (or a file it imports) may now use a
relative path in its `file+noindex:` URL, for example
`url: file+noindex:vendor`. The path is resolved against the project root, so a
local repository can be committed together with the project. Previously such a
path was resolved against the current working directory, which cabal warned
was fragile. Paths in the global `~/.config/cabal/config` are unchanged.
